# Практика к семинару 1-5 «Формы и хранилища»

За 50 минут вы превратите готовую страницу в работающий черновик заявки на веб-мастерскую.

Это **практика на занятии**, а не домашняя работа. Новую верстку придумывать не нужно: HTML-структура и CSS уже
подготовлены. Основная работа пройдет в `script.js`; в блоке 2 потребуется добавить несколько HTML-атрибутов.

## Что получится

К концу занятия страница будет уметь:

- обрабатывать отправку формы без перезагрузки;
- не принимать пустое имя, неверный email и невыбранную тему;
- показывать введенные данные на странице;
- сохранять заявку в `localStorage` как JSON;
- восстанавливать поля после перезагрузки;
- удалять черновик;
- создавать временную копию в `sessionStorage`.

## План работы

| Время       | Блок                        | Видимый результат                                  |
|-------------|-----------------------------|----------------------------------------------------|
| 00:00–10:00 | 1. Форма и `submit`         | сообщение появляется без перезагрузки              |
| 10:00–20:00 | 2. HTML-валидация           | браузер останавливает неверный ввод                |
| 20:00–30:00 | 3. `FormData`               | имя, email и тема появляются на странице           |
| 30:00–40:00 | 4. JSON и `localStorage`    | появляется сохраненный черновик                    |
| 40:00–50:00 | 5. Восстановление и очистка | данные переживают перезагрузку и удаляются кнопкой |

В каждом блоке — три коротких задания. Выполняйте их сверху вниз: следующий блок использует результат предыдущего.

## Запуск

1. Откройте папку проекта в VS Code.
2. Запустите `index.html` через **Live Server**.
3. Откройте DevTools: понадобятся вкладки **Console** и **Application**.
4. Откройте [TASKS.md](TASKS.md) и начните с блока 1.

Ничего устанавливать не нужно. Для хранилищ важно работать через Live Server, чтобы у страницы был стабильный origin.

## Как не потерять темп

- Сначала выполните обязательную часть задания, затем улучшайте код.
- После каждого шага сохраняйте файл и проверяйте страницу.
- Если шаг занял больше трех минут, отметьте его и переходите дальше вместе с группой.
- Не меняйте дизайн во время занятия: он уже готов и не оценивается.

## Отправка на GitHub

Перед сдачей убедитесь, что изменены `index.html` и `script.js`, затем выполните обычный цикл:

```bash
git status
git add index.html script.js
git commit -m "Complete forms and storage practice"
git push
```

Прикрепите ссылку на репозиторий в форму сдачи. Если репозиторий создается прямо на занятии, не забудьте добавить remote
перед `git push`.

## Финальная демонстрация

Для проверки преподавателю достаточно показать четыре действия:

1. отправка некорректной формы блокируется браузером;
2. корректная заявка появляется на странице;
3. после перезагрузки значения восстанавливаются;
4. кнопка «Удалить черновик» очищает форму и хранилища.
